Izveidot tīmekļa lietotni, kurā iestādes darbinieks izvēlas dokumenta veidni, ievada nepieciešamos datus un iegūst gatavu dokumentu. Mērķis — samazināt atkārtotu manuālu teksta ievadi un kļūdas.
Kas jāizveido
1. Dokumenta veidnes izvēle (piemēram, iesniegums, atbildes vēstule vai akts).
2. Ievades lauki: vārds, uzvārds, iestāde, datums un dokumenta saturs.
3. Automātiska ievadīto datu ievietošana veidnē, aizstājot mainīgos, piemēram, {vards} un
{datums}.
4. Gatavā dokumenta priekšskatījums pārlūkā.
5. Dokumenta lejupielāde PDF formātā.
